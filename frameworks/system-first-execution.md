# Framework: System-First Execution

## Definition
Relying on repeatable, tested processes over individual persuasion; delegating long-term monitoring to ensure consistency.

## Components
- Process reliance
- Role delegation
- Consistency tracking
- Post-sale system handoff

## Application
Used to structure the engagement so the system carries the weight, not the salesperson's performance.

## What It Replaces
The hero-salesperson model and reliance on individual talent for repeatable results.
